# Brand Guidelines

## Purpose
Define the visual and verbal personality of AI Crop Advisory Platform.

## Goals
- Feel professional, modern, trustworthy, and agriculture-aware.
- Avoid a student-project or template look.
- Keep language clear for technical and non-technical users.

## Best Practices
- Use direct labels such as Crops, Dashboard, Search, Create, Update.
- Pair agriculture cues with SaaS restraint.
- Keep copy short and practical.

## Examples
- Primary label: "Add crop".
- Error copy: "Unable to load crops. Check the backend server and try again."

## Do
- Use confident, plain English.
- Keep brand cues subtle: leaf icon, green primary, harvest accent.

## Don't
- Overuse farming metaphors.
- Add decorative illustrations where real data should be the focus.

## Real SaaS References
Stripe for clarity, Vercel for minimal branding, GitHub for task-oriented labels.

## Implementation Notes
The brand mark is text plus a Lucide leaf icon. No backend behavior is tied to branding.
