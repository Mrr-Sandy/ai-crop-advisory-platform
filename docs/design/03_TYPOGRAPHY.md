# Typography

## Purpose
Define type scale, weight, and rhythm.

## Goals
- Make crop data easy to scan.
- Keep headings strong without oversized marketing type.
- Support mobile readability.

## Best Practices
- Use system UI fonts for speed and reliability.
- Use line height around 1.5 for body text.
- Use semibold for section headings and medium for labels.

## Examples
- H1: 40px desktop, 32px mobile.
- H2: 28px desktop, 24px mobile.
- Body: 16px.
- Small metadata: 14px.
- Button: 14px or 16px medium.

## Do
- Keep letter spacing normal.
- Use concise headings.

## Don't
- Scale text with viewport width.
- Use hero-sized text inside cards or forms.

## Real SaaS References
GitHub and Notion for readable density, Stripe for polished hierarchy.

## Implementation Notes
Use Tailwind classes such as `text-sm`, `text-base`, `text-2xl`, `font-medium`, `font-semibold`, and `leading-relaxed`.
