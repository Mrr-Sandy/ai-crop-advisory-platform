# Iconography

## Purpose
Define icon usage.

## Goals
- Improve recognition of actions and states.
- Keep the product professional.
- Avoid custom inconsistent icons.

## Best Practices
- Use Lucide React icons.
- Pair icons with text for primary workflows.
- Use icon-only buttons only when the action is familiar and labeled with `aria-label`.

## Examples
- Leaf for brand.
- Search for search input.
- Plus for add crop.
- Pencil for edit.
- Trash for delete.

## Do
- Use consistent icon sizes, usually 16px or 20px.
- Add accessible labels.

## Don't
- Use emoji as functional UI.
- Mix multiple icon styles.

## Real SaaS References
GitHub Octicons-style clarity, Material Design action icons, Vercel minimal icon buttons.

## Implementation Notes
Install and import from `lucide-react`. Icons must support actions without changing backend behavior.
