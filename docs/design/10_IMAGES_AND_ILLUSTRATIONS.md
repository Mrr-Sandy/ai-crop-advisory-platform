# Images And Illustrations

## Purpose
Define media usage for agriculture context.

## Goals
- Use visuals that feel credible.
- Avoid cartoon or generic AI-template imagery.
- Keep real data more important than decoration.

## Best Practices
- Prefer high-quality agriculture photography or restrained generated assets.
- Use images for context, not for replacing product functionality.
- Optimize assets for web delivery.

## Examples
- A field image may support a landing hero.
- Crop cards should not use decorative images unless the backend provides image data.

## Do
- Keep image treatments subtle.
- Use meaningful alt text.

## Don't
- Use fake crop photos as if they came from the backend.
- Use dark, blurred, or hard-to-inspect imagery for product data.

## Real SaaS References
Stripe editorial imagery, Vercel restrained media, Notion practical content visuals.

## Implementation Notes
The current crop API does not provide image URLs, so crop cards remain text-first.
